# My App Admin Panel

This is the admin panel for the My App platform.

## Getting Started

1.  **Install Dependencies**
    ```bash
    npm install
    ```

2.  **Start Development Server**
    ```bash
    npm run dev
    ```

## Project Structure
- `src/`: Source code
- `docs/`: Development documentation

## Note on Location
This project was initialized inside the `my-app` directory due to automation constraints.
If you wish to move it to be a sibling of `my-app` (e.g., `../my-app-back`), you can manually move the folder:

```bash
# From the parent directory of my-app
mv my-app/my-app-back ./my-app-back
```
